# 3:4 竖屏适配规范

本文件只在用户选择 `3:4` 时读取。竖屏不是把 16:9 缩小、裁切或把左右栏硬塞进窄画布，而是保留同一内容、风格 DNA、信息原语和四段式镜头，重新注册竖向构图。

## 1. 画幅契约

- 输出尺寸固定为 `1080×1440`，使用 [base-template-portrait.html](../assets/base-template-portrait.html)。
- 同一文件只允许一种画幅。16:9 使用 `base-template.html` + `L01-L10`；3:4 使用竖屏基座 + `V01-V10`。
- 用户未指定时默认 16:9；明确说竖屏、小红书卡片比例、3:4 时才选择 3:4。
- 不改口播顺序、因果、例子和核心结论。只重排屏幕文字、构图轨道和动画方向；内容过密时拆 beat/step，不删逻辑。
- `styles/{id}.md` 中若出现横向构图示例，只继承风格 token、签名组件和动效个性；具体轴线与分区以本文件和 V 骨架为准。

## 2. 竖版空间骨架

安全区：左右 `80px`，上下 `112px`；主内容距底部 HUD 至少 `112px`。

竖屏按五个纵向区思考，不要求每页都画出五块：

| 区域 | 建议高度 | 用途 |
|---|---:|---|
| header/meta | 56-90px | kicker、章节号、来源 |
| title/lead | 220-360px | 第一眼落点 |
| visual/body | 620-820px | 关系变化、截图、路径、证据 |
| lock strip | 100-180px | 结论、记忆点、状态推进 |
| footer safe | 52-88px | HUD 与呼吸 |

硬约束：

1. 最终态有效构图纵向跨度应达到舞台高度的 `62%-86%`；常规内容页底部空白不得超过 `26%`。
2. 主视觉占注意力 `45%-65%`，辅助结构 `20%-35%`。不能把所有文字压在画面中间 40%。
3. 常规内容页必须使用上、中、下至少 3 个纵向锚点。Claim/结尾页允许更空，但需写 `data-portrait-airy="true"`，并用顶部 meta 与底部 lock 建立方向。
4. 每屏最多 2 个大信息区；第三层只能是标签、来源、短结论或进度。
5. 截图/证据是主视觉时占舞台高度 `45%-65%`，使用 `contain/max-width/max-height`，禁止 `cover`。
6. 禁止 `justify-content:space-between` 或 flex spacer 把少量内容机械顶到上下两端；用明确 grid rows 和组间距控制节奏。

## 3. 横转竖映射

| 16:9 语义 | 3:4 做法 |
|---|---|
| L01 左轴概念揭示 | V01 顶部标题先占地，签名视觉/记忆条落到中下部 |
| L02 中轴收束 | V02 上下呼应定格：上部章节锚点、中部金句、底部标签/结论条 |
| L03 左右对比 | V03 上下对比，旧状态在上，新状态在下；新状态推进时旧状态灰化 |
| L04 横向流程 | V04 纵向流程，连接线独占竖轨，当前节点沿 y 轴推进 |
| L05 纵向层级 | V05 保持纵向，但增加层级尺寸差与底部锁定句 |
| L06 3×2 矩阵 | V06 改 2×2 或 2×3；超过 6 项拆 beat |
| L07 数字主屏 | V07 数字占中上部，解释与结论在下部形成第二锚点 |
| L08 横向证据板 | V08 证据上下排：标题/结论在上，主证据占中部，来源在下 |
| L09 截图+侧栏 | V09 截图占中上部，说明改为底部短栏，不压图 |
| L10 核心外扩 | V10 核心在上或中上，最多 3 个能力沿纵向/2列展开，连线不交叉 |

禁止转换：

- 左右栏按比例缩窄后继续并排。
- 横向 4-5 节点压成一行。
- 16:9 大标题字号不变，依靠溢出或单字换行勉强塞入。
- 把横版截图裁成竖条。
- 只修改 `--stage-w/h`，其余布局完全不动。

## 4. 竖版排版

- hero 标题：`88-132px`，纯文字页可到 `148px`；每行 3-7 个汉字，最多 9 个。
- 页面标题：`64-92px`；卡片标题：`32-44px`；正文：`28-34px`；标签：`20-24px`。
- 标题行高 `1.08-1.18`，正文 `1.45-1.62`。中文 `letter-spacing:0`。
- kicker→标题 `24-36px`；标题→主视觉 `48-72px`；主视觉→结论 `48-80px`。
- 禁止单字孤行。若最后一行只有 1-2 个字，先改断句或缩短屏幕文案，再微调字号。
- 竖屏优先共享左轴；居中只用于 V02/V07 的强定格，不得每页居中。

## 5. 竖版动画

仍执行 `glance → reconstruct → push → lock`，但运动方向随构图转置：

- 横向路径 `scaleX/x` → 纵向路径 `scaleY/y`。
- 左右对比让位 → 上下对比让位。
- 截图侧栏进入 → 截图先落位，底部注释随后上推。
- 矩阵按阅读顺序逐组揭示：左上→右上→左下→右下。
- push 优先使用 `y ±16-28px`、`scale .94-.98`、亮度/模糊层级；不要让整页大幅上下漂移。

最终态必须完全静止，并可作为 3:4 单帧截图独立成立。

## 6. 生成前快检

1. 画幅是否锁为 `1080×1440`，并使用 V 编号？
2. 主视觉是否先占中上或中下的大区域，而非文字集中在正中？
3. 最终态是否覆盖至少 3 个纵向锚点？
4. 横向关系是否真正转置，而非压窄？
5. 标题是否按短语断行，无单字/双字尴尬尾行？
6. 最终截图是否有明确第一眼落点和底部记忆锁？
