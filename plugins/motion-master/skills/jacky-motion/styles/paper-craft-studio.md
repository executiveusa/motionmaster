# 剪纸工作室讲解风 (paper-craft-studio)

适用：课程内容、教育解释、AI 工具教学、亲和品牌、轻量产品说明与友好型方法论。
气质：暖纸工作台 × 干净剪纸拼贴。像在工作室里把概念一层层摆清楚，手作但不幼稚，亲切但不松散。
记忆钩子：暖米纸工作台 + 奶油白信息纸面 + 剪裁纸片 + 轻柔错层阴影 + 克制的蓝/珊瑚/芥黄/鼠尾草色块。

## 视觉不变量

1. **材质**：暖米色画布、奶油白主纸、极淡纸纤维纹理；阴影柔和且短，不做厚描边、硬黑投影或做旧撕纸。
2. **色**：钴蓝 `--accent` 是唯一主强调；珊瑚 `--accent-2`、芥黄 `--paper-yellow`、鼠尾草 `--paper-sage` 只承担分组。单屏最多出现 3 种彩色纸片；核心页至少形成“奶油白纸面 + 主强调 + 1 个分组色”的层次，禁止退化成米色底加黑字。
3. **字**：Noto Sans SC 同时负责标题与正文，标题用 900、正文用 500-700 建立层级；IBM Plex Mono 负责编号与工坊标签。禁止标题与正文混用衬线/无衬线造成割裂；标题按短语断行，无单字孤行。
4. **构图**：暖米色只作为工作台背景，主标题或主信息优先落在奶油白 `.paper-heading` / `.paper-sheet` 上；每屏以 1 张主纸片或 1 个主色块作为第一眼落点，辅助纸片不超过 2 组。底层保持明确 grid，旋转控制在 ±0.8°，使用裁边的纸片不超过 3 张，留出 20%-30% 的方向性空白。
5. **标题关系**：`.paper-label` / `.kicker` 必须按文字收口，使用 `width:max-content; max-width:100%`，不能被 grid 拉成长条；标签与标题视觉间距保持 28-52px，禁止贴字。章节可用鼠尾草/芥黄/珊瑚标签分组，但蓝色仍是主强调。
6. **纸面层次**：长标题不可直接漂在大面积米色背景上；优先使用奶油白标题纸面、轻错层底纸与 2-3 个短色签形成前后层次。白纸区域承担阅读，彩色纸片承担分组与锁定，不靠堆卡片增加颜色。
7. **运动**：纸片从 16-28px 的短距离滑入后轻落定，色块沿轴线推出，胶带只做一次按压；不弹跳、不旋转飞入、不循环漂浮。

## 签名组件（assets/styles/paper-craft-studio.css）

`.paper-heading`（奶油白标题纸面）· `.paper-sheet`（主纸张）· `.paper-tile`（辅助剪纸卡）· `.paper-cut-a/.paper-cut-b`（克制裁边）· `.color-block`（干净色块）· `.tape-soft`（半透明纸胶带）· `.paper-label`（工坊标签）· `.folio-tab`（低权重页码）· `.paper-stack`（错层纸堆）

## 运动个性提示

入场优先 `expo.out` / `power3.out`，位移 16-28px、时长 0.45-0.75s；主纸先落位，再让色块沿同一轴线推出，最后用标签或短规则线锁定。旋转写在 CSS 终态，动画只做短位移与透明度。

## 版式偏好

16:9 优先 L03 左右对比（两张异材质纸片）/ L04 横向流程（连续色块）/ L05 纵向层级（纸张叠放）/ L06 矩阵网格（有焦点的课程模块）/ L09 截图主屏（纸框承载真实界面）。
推荐 recipe：split-reveal / path-build / stack-expand / claim-lockup。

## 3:4 竖屏转置

3:4 继续使用同一风格 CSS，但必须从 `V01-V10` 选骨架，不能缩窄 L 骨架：

1. **V01 概念揭示**：奶油白 `.paper-heading` 占中上部，主标题先落位；中下部用 1 张 `.paper-sheet` 或 1 个 `.color-block` 建立第二锚点，底部短标签完成 lock。
2. **V03 上下对比**：旧状态在上、新状态在下，两张纸片必须异材质或异分组色；分隔线改为水平，第三步旧纸降亮、新纸推进。
3. **V04 纵向流程**：3-5 个纸片节点沿 y 轴排列，连接线独占竖轨并用 `scaleY` 生长；禁止把横向彩条压成窄行。
4. **V05 层级展开**：纸张由上到下逐层内缩，形成工作台上的叠放关系；底部保留一句蓝色或珊瑚色记忆锁。
5. **V06 竖版矩阵**：只用 2×2 或 2×3，当前行使用彩色纸片，其余保持奶油白，禁止六格同亮。
6. **V09 截图展示**：真实界面放进 `.paper-sheet`，占舞台高度 45%-60%；说明落到底部纸签，不在截图旁塞窄栏。

竖屏仍遵守单屏最多 3 种彩色纸片、1 张主纸 + 最多 2 组辅助纸片。主纸、标题纸和底部 lock 要覆盖上中下三个锚点，避免所有剪纸集中在画面中部。

## 风格禁忌

1. 厚描边贴纸、硬黑阴影、满屏胶带票据——那是 `paper-collage`。
2. 红笔圈注、手绘乱线、素描式 SVG——那是 `sketch-note`。
3. 做旧报纸、撕裂证据、档案编号堆叠——那是 `newspaper-evidence`。
4. 毛玻璃、霓虹渐变、悬浮 UI 卡片。
5. 三张等宽同亮卡片、卡片套卡片、随机 absolute 散点。
6. 把“手作感”理解为大角度倾斜、粗糙字体或儿童化装饰。
