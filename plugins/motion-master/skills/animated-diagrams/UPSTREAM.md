# Upstream

`animated-diagrams` is imported from **https://github.com/omkamal/animated-diagrams-skill**.
- Licence: Apache-2.0

Semantic SVG scenes choreographed with GSAP 3 and rendered by HyperFrames. Twelve style presets, six camera patterns for flows larger than the canvas, Arabic and RTL support, and a voiceover mode where every beat fires on its SRT cue.

The upstream licence file is included in this directory and applies to every
file here that came from upstream. Anything written for Motion Master itself
and shipped alongside it is licensed separately — see `../../LICENSE.md`.
