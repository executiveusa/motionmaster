How it works

Three steps, and only the last one needs a renderer.

The agent is the author. You are the person who reads the frame and says whether it is right.

  1. 01

    You describe it

    The brief

    14s launch film, name reveal, hold 2s, calm exit

    A sentence, a brief, or a screenshot of what you want. The agent reads it the way a director reads a note: what is on screen, how long it holds, how it ends.

  2. 02

    It writes the shot list

    Storyboard

    Storyboard beats for the sample brief
    Beat In What happens Easing role
    beat 1 0:00 title in entrance · ease-out
    beat 2 0:05 subtitle on-screen · ease-in-out
    beat 3 0:09 cards stagger entrance · ease-out · 40ms
    beat 4 0:13 hold and exit exit · ease-in

    Beats, timing, easing role and stagger budget are decided before a line of code is written, so the motion is a plan rather than an improvisation.

  3. 03

    It writes and renders the video

    A slice of the composition

    import { AbsoluteFill, interpolate, useCurrentFrame } from 'remotion';
import { gsap } from 'gsap';

export const LaunchTitle = () => {
  const frame = useCurrentFrame();
  const opacity = interpolate(frame, [0, 24, 120, 150], [0, 1, 1, 0], {
    extrapolateLeft: 'clamp',
    extrapolateRight: 'clamp',
  });
  return (
    <AbsoluteFill style={{ backgroundColor: '#111113', opacity }}>
      <Title />
    </AbsoluteFill>
  );
};

    Remotion renders the frames, GSAP runs the choreography, ffmpeg writes the file. The project stays on your machine, and the project is the video.

You pay once and the file is yours forever. No credits, no watermark, no model that can be retired underneath you. Your project renders on your own machine, so the twelfth video costs nothing.

“I don’t know how to code.”

You don’t. You paste a sentence into your agent and it comes back with a video. If you want to change a word later, you type the change — the project is text, and text is something you can read.

Questions

The questions we are actually asked.

Which agents does it work with?

ChatGPT, Codex, Claude and Cursor, plus twelve more hosts, from one package. The install is a plugin manifest and a single MCP URL — the same command shape in every host that supports plugins.

What is actually in the package?

The skill pack, the plugin package, the prompt library and the token and starter libraries, plus a one-line install command for the host you use. The exact command for your host is in the purchase email.

Do I need to install anything to try it?

You can paste any prompt from this page into a chat agent and see the brief yourself. The licence is what adds the skills, the tokens and the render pipeline that turn that brief into a finished file.

Does it run on my own computer?

Yes. The project renders locally with Remotion on your own machine, so there is no per-minute fee and no queue. If you would rather not install a renderer, Studio includes an optional hosted render allowance.

Can I use the result for client work?

Yes. The video, the project and the code are yours to use commercially, including for clients, with no attribution required.

What if I want my own footage in it?

That is the Montage bridge, included in Studio. It runs against a Montage instance you control, so your footage stays on your machine. The bridge is AGPL-3.0 and ships as a separate, isolated work.
